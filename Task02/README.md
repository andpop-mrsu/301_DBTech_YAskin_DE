# Task02 — ETL данных в SQLite

## Назначение

В данной лабораторной работе выполняется загрузка исходных данных о фильмах, рейтингах, тегах и пользователях в базу данных SQLite.

## Структура проекта

- `movies.csv` — данные о фильмах;
- `ratings.csv` — оценки пользователей;
- `tags.csv` — пользовательские теги;
- `users.txt` — данные пользователей;
- `genres.txt` — список жанров;
- `occupation.txt` — список профессий;
- `make_db_init.py` — утилита формирования SQL-файла;
- `db_init.sql` — SQL-скрипт создания и заполнения таблиц;
- `db_init.bat` — скрипт запуска формирования базы данных;
- `movies_rating.db` — база данных SQLite.

## Требования

Для работы необходимы:

- Python 3;
- SQLite 3.

Команды `python3` и `sqlite3` должны быть доступны из командной строки.

## Запуск

Для создания и заполнения базы данных необходимо выполнить:

```bash
bash db_init.bat
